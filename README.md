## Things I've built

| Project | What it is | Try it |
|---|---|---|
| [**Gauge**](https://github.com/bryanfrds/Gauge) | A small open-source AI that picks the answer from a list and says how sure it is. Trained on a laptop in 21 minutes, it went from 73.6% to 90.5% on finance tweets it had never seen. | [Read the post](https://www.linkedin.com/posts/bryanljy07_ai-machinelearning-opensource-activity-7513125556532498432-o6Be) |
| [**CodeMon**](https://github.com/bryanfrds/Codemon) | A creature-collecting RPG in plain JavaScript: 1,000 CodeMon, type matchups, evolution, area guardians and a shop. It can play itself. | [▶ Play](https://bryanfrds.github.io/Codemon/) |
| [**Pixel Dungeon**](https://github.com/bryanfrds/dragons-dungeon-game) | A dungeon crawler where the AI fixes "bugs" floor by floor while you work. Procedural floors, loot and a shop between floors. | [▶ Play](https://bryanfrds.github.io/dragons-dungeon-game/) |
| [**pr-reactions**](https://github.com/bryanfrds/pr-reactions) | A Claude Code hook that pops up a picture and plays a sound when an AI code review approves or rejects a pull request. | macOS |
| [**herdr-game-pane**](https://github.com/bryanfrds/herdr-game-pane) | Streams those two games into a terminal side pane while Claude Code is busy, using a headless browser. | |

CodeMon, Pixel Dungeon and pr-reactions have automated tests that run on every pull request.
